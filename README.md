# El Hub — kiosco

Kiosco de El Hub, Saddleback Buenos Aires. Se publica en GitHub Pages:
**https://apalamara.github.io/hub-kiosco/**

## Esto es un espejo, no la fuente

No se edita acá. Este repo existe solo para publicar, porque el repo de
trabajo es privado y GitHub Pages en repos privados es pago.

La fuente es `output/` del repo `Apalamara/Hub`. Lo que hay acá es una copia
de esa carpeta con dos diferencias a proposito:

- `kiosco.html` se copia como `index.html`, para que la URL sea la pelada
- no se copia `output/index.html`, que es el dashboard interno del equipo

Para actualizar se corre `publicar.sh` desde el repo de trabajo.
